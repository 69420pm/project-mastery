# When should the tutor show a worked example, and how fast should it fade into independent practice?

**Decision:** The sequence of example, completion problem and independent problem for each new skill.

**Why it's uncertain:** Worked examples help novices but can hurt more advanced learners (expertise reversal), and principle 1 wants the student doing the thinking.

## Sub-questions

- When do worked examples beat problem solving, and when does it reverse?
- How should fading be paced and triggered?
- How does productive failure compare for STEM concepts?

## What would change the design

Sets the rule for when the tutor demonstrates versus asks.
