# Supabase Storage with supabase-js

Installed: `@supabase/supabase-js` 2.117.2, `storage-js` 2.117.2. The only docs shipped are TSDoc, so read `node_modules/.pnpm/@supabase+storage-js@2.117.2/node_modules/@supabase/storage-js/src/packages/StorageFileApi.ts`.

- **No upload progress.** `upload`, `update` and `uploadToSignedUrl` all go through the `post`/`put` fetch helpers (StorageFileApi.ts:143). There is no `onUploadProgress`. For a progress bar, call `createSignedUploadUrl(path, { upsert })` (line ~382; token valid 2 hours; needs insert RLS), then send the bytes with XHR and `xhr.upload.onprogress`. Unverified: `uploadToSignedUrl` wraps a Blob in multipart FormData, so check the live API accepts a raw-body PUT before relying on it. storage-js has no TUS or resumable client.
- **Return shape.** Every method returns `{ data, error }` and resolves rather than throws. `upload` gives `{ id, path, fullPath }`. `createSignedUrl(path, expiresIn)` gives `{ signedUrl }`. `remove(paths[])` gives `FileObject[]`. `download(path)` is a builder; `await` it to get a `Blob`.
- **Object info.** `info(path)` (line ~961) returns camelCased fields (`recursiveToCamel`): `size`, `contentType`, `createdAt`, `lastModified`, `etag`, `metadata`. Use it to verify an upload server-side. Run it with the user's client so RLS applies. Its TSDoc does not state the policy; that `select` is needed is inferred from `download`.
- **Errors.** `error` is `StorageApiError` (`status: number`, `statusCode: string`, `code`), `StorageUnknownError`, or base `StorageError` (`lib/common/errors.ts`). Test with `isStorageError`. Log the whole object; `message` hides `statusCode`.
- **Upload defaults.** `upsert` is false, so a duplicate path errors. `contentType` defaults to `text/plain;charset=UTF-8` for non-Blob bodies, so set it. `cacheControl` defaults to 3600.
- **Bucket and policies.** `supabase/migrations/20261006100200_create_course_files_bucket.sql`: private bucket `course-files`, 50 MB limit, MIME allowlist (PDF, PNG, JPEG, WebP). Four policies on `storage.objects` for `authenticated`, each checking `(storage.foldername(name))[1] = auth.uid()::text`. Upserts need select, insert and update together. pgTAP tests: `supabase/tests/database/course_files_storage.test.sql` (`pnpm db:test`).
