# File input limits: MiMo, Gemini and AI Gateway

- **MiMo.** The AI Gateway model list (`https://ai-gateway.vercel.sh/v1/models`, 2026-10-14) shows `xiaomi/mimo-v2.6-flash` with image, audio and video input and the `vision` tag but no file input: page images work (verified through the parse smoke check). A text PDF attached as a file part was read correctly ("Limits and continuity") through DeepInfra, with no AI SDK warning; a scanned PDF is unverified. `openai/gpt-4.1-nano` and `openai/gpt-5-nano` read the same PDF too. `@ai-sdk/google` 4.0.95 is installed for local development on the Gemini API (ADR 0016); the next line applies when a task's `AI_MODEL_*` override points at a Google model.
- **Gemini inline size.** The `@ai-sdk/google` 4.0.95 docs (`docs/15-google.mdx`, "File Inputs", lines ~457-520) give no inline limit for `generateContent`. The only "20 MB" figure is the Batch threshold (line ~1272): smaller batch bodies go inline, larger ones use the Files API. The docs say the SDK downloads URLs passed as data, except Gemini Files URIs (`https://generativelanguage.googleapis.com/v1beta/files/`) and YouTube URLs. Larger files: `google.files()` (`dist/index.d.ts`, `files(): FilesV4`) and `uploadFile` (`node_modules/ai/docs/03-ai-sdk-core/39-file-uploads.mdx`). Upload references are per provider.
- **Gateway URL handling.** `@ai-sdk/gateway` 4.0.103 sets `supportedUrls = { '*/*': [/.*/] }` (`src/gateway-language-model.ts:35`), so the SDK does not download URLs and the gateway receives them. File bytes are base64-encoded (`gateway-language-model.ts:~207`).
- **PDFs on non-Google models.** The gateway docs (`docs/00-ai-gateway.mdx`) say nothing about PDF or file input for any provider. The only input capability tag in `providerOptions.gateway.has` is `'vision'`, described as image input (`src/gateway-provider-options.ts:69-85`). There is no `pdf` or `file` tag. Whether `xiaomi/mimo-v2.6-flash` accepts `application/pdf` is not in the installed docs. Check it with one live call.
- **Repo.** `src/lib/ai/models.ts` (`AI_TASKS`) makes `xiaomi/mimo-v2.6-flash` the default of the text tasks; no task has a fallback (`fallbacks: []`), and locally the overrides point them at `google/gemini-3.5-flash-lite`. Ingest works from page images (ADR 0007), so no PDF is sent there; the Chat does send attached PDFs.
