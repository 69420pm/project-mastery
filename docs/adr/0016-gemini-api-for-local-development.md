# Local development on the Gemini API free tier

**Context.** Local development runs on AI Gateway's monthly free credit ([ADR 0006](0006-ai-cost.md)), and MiMo V2.6 Flash does the text work there. The credit serves no Google model: every Gemini id returns 403 through the gateway ([PR #79](https://github.com/69420pm/project-mastery/pull/79)). The Gemini API's free tier gives 500 requests a day on Gemini 3.5 Flash Lite (the developer's figure), which covers a day of development calls. The free tier may use prompts to improve Google's products, which ADR 0006 already accepts for test materials only. Embeddings must match the `chunks.embedding` column (2048 dimensions, Cohere's output), so they stay on the gateway.

**Decision.** Local development sends the text tasks to `google/gemini-3.5-flash-lite` on the Gemini API directly, with `GOOGLE_GENERATIVE_AI_API_KEY`. The developer's `.env.local` selects it per task through the `AI_MODEL_*` overrides: chat, brief, title, ingest, map, exercise and topic. Embeddings and MiMo stay on AI Gateway. A `google/` id without the key is an error. Deployments refuse the key, so the free tier never sees a Student's data. Smoke checks pin every generating task to the same Gemini model locally (`evals/smoke.ts`), because MiMo through DeepInfra can take minutes per check. `AI_SMOKE_MODEL=xiaomi/mimo-v2.6-flash` runs a check on MiMo through the gateway, the model that ships, and is the way to check MiMo before a release. This supersedes the local-development parts of [ADR 0005](0005-ai-sdk-through-gateway.md) and [ADR 0006](0006-ai-cost.md): locally, text tasks no longer go through the gateway, and development no longer uses only the gateway's credit. Preview and production are unchanged.

**Consequences.** Local text calls spend no gateway credit; the development budget becomes the Gemini daily quota, and embeddings still spend a fraction of a cent per parse. Development now runs a different model from production, so a spec's smoke check passes on Gemini without showing that MiMo works. MiMo-specific behaviour, such as structured output on DeepInfra and its quality, is first seen in `AI_SMOKE_MODEL` runs or in preview. Flash Lite's arithmetic is weaker than MiMo's (`docs/agents/notes/ai-sdk.md`), so checks of answer quality differ locally. Google sets the free tier's limits and data terms, and they can change; check AI Studio before relying on them.
