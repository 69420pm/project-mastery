# Questions as first-class objects

**Context.** Until M1 (#173) the AI recorded evidence with one `recordAttempt` call per problem: a correct-or-not flag per KC, written after the fact and tied to nothing in the Chat. Nothing linked an attempt to the question that was asked or the answer that earned it, so grading could not be checked, a numeric answer could not be compared with the Exercise's key, and later modes (review, practice, mock exams) had no session to belong to.

**Decision.** Three owner-only tables replace the old log. `study_sessions` holds one row per Chat (`chat_id` unique), started by a database trigger when the Chat is inserted, with its Course, `mode` (`learn`, `review`, `practice`, `mock`, `results`), `topic_id` and `stage` (null until Topics and stages exist) and `started_at`/`ended_at`. `questions` holds each graded question the AI asks in a session: its `kind`, Markdown `prompt`, optional Exercise, the Student's answer (`answer_text`, `answer_message_id`) and when it was asked, answered and graded; its KCs are in `question_kcs`. `attempts` is recreated as the grade of one question on one of its KCs: `kind` (`pre` or `learn`), `result` (`full`, `partial`, `wrong`), `help`, and `check` (`match`, `mismatch` or null) for the numeric comparison. Row Level Security lets a Student add attempts only on KCs their own question tests, in that question's session, and never change one. A deleted Chat leaves its session (`chat_id` set null), so the learning evidence survives; a deleted Course takes everything. A Course's attempts are read through their session's `course_id`. Until FSRS replaces the review ladder (M2), it reads `full` as correct and `partial` and `wrong` as incorrect.

**Consequences.** The migration deletes every Chat and attempt, which were test data, and drops `chats.model_choice` with the Chat's model picker: the Chat runs on one model. Reads of a Course's attempts join `study_sessions`. Grading, the numeric check and evals can now point at a stored question and answer. Exercises gain `final_answers` for the numeric check; those analysed before stay null until their map is rebuilt.
