# Chat feature

Build a simple AI chat interface like the Claude App, it should be simple, just text, no media files but has all basic features you need.
Every logged in user can have multiple chats that get stored on his account.
Chats can also get deleted by the user.
In a left sidebar all chats get listed and can be clicked on.
The user can also switch between models.
As AI in local development mode, the google generative ai gets used and ai gateway for everything else (which can't be used currently but will be used in the future).
